# Typed coding-interface development controls

Experiment code and reports: Copyright (c) 2026 Prashant Jagtap, MIT License.

The two task instructions, grader excerpts and task-derived traces originate from
[Terminal-Bench 2.1](https://github.com/harbor-framework/terminal-bench-2-1)
at revision `7131e4375048a0e408a8fb404b5f499d726b695b`, Apache License 2.0.
Task authors: Alex Shaw (`cancel-async-tasks`) and Orfeas Menis Mastromichalakis
(`log-summary-date-ranges`). See the retained [Apache license](../terminal-pilot-v1/upstream/LICENSE).
The source inventory and native controls remain in each registration.

Local pretrained models are Qwen2.5-1.5B-Instruct and Qwen2.5-Coder-7B-Instruct
from the Qwen team, served as pinned Ollama Q4_K_M artifacts. These experiments
do not train, redistribute or change their weights. No hosted-provider calls occur.

All task material, grader output and model trajectories are evaluation-only.
These repeatedly inspected tasks are development/regression cases, not untouched
test data, a full benchmark or training episodes. The schema-copy canaries and
literal file probes are authored engineering controls. They measure interface
behavior, not coding competence. No candidate is promoted.
